# 📶选择一台合适的路由器

::: tip
以下为通用选购要点，具体网络环境请以港科广校园网实际条件为准。
:::

## 是否需要购买路由器？

除非你有以下需求，学校提供的网络服务一般来说已经够用了：

- 宿舍无线信号覆盖较差，或个人设备较多需要扩展局域网。
- 需要连接台式机、开发板、存储服务器等有线设备。
- 希望使用无 DHCPv6 功能的设备访问 IPv6。

## 不刷机

若校园网墙壁网口速率为 1Gbps，购买 AX3000 规格的千兆路由器即可，如主流品牌 150 元价位的 AX3000 系列（联发科方案性价比高）。

## 刷机 / 软路由

- 可参考[恩山论坛](https://www.right.com.cn/forum/forum-171-1.html)，选择刷机支持较好的型号（如小米 AX3000T 等）。
- 若只作 AP 使用，可考虑 [NanoPi R2S](https://wiki.friendlyelec.com/wiki/index.php/NanoPi_R2S) 等多网口开发板作软路由。
