# 📚 图书馆

来源：学校国际学生手册「Library Services」（2025-05-07），见 [studyathkustgz.hkust-gz.edu.cn/StudentSupport](https://studyathkustgz.hkust-gz.edu.cn/StudentSupport)。

港科广图书馆是一座智慧图书馆，兼具画廊、档案馆、博物馆与文化交流场所职能，是港科广社群聚集、学习、创造与协作的「第三空间」。

## 资源与服务

- **统一检索**：通过 PowerSearch 查找全部馆藏。
- **纸质图书**：用手机或自助借还机借书；借还规则见 Borrow & Return，用 StackMap 可视化工具锁定书架位置。
- **报刊杂志**：位于 1F，仅供馆内阅览。
- **课程教材（Course Reserves）**：任课教师预留的课程参考书，可在 2F Ask Us Desk 借阅纸质版（每次 3/24 小时），数字版可 7×24 在线访问。
- **电子资源**：连接校园网即可访问；校外远程访问需配置 VPN。
- **馆外资源**：可提交馆际互借（ILL）申请或向图书馆荐购资源。
- **LibGuides**：学科/课程核心资源使用指南。
- **图书馆工作坊**：各类主题与数据库的开放讲座。
- **ChatBot**：图书馆主页的 AI 助手，可咨询资源、服务与设备问题。
- **研究咨询**：图书馆研究支持人员提供线上线下/邮件咨询，可预约一对一。
- **论文提交**：港科广学位论文均以电子版形式收录，通过在线论文提交系统提交。
- **Reading List**：图书馆协助建设课程阅读清单，经 Canvas 无缝访问课程材料。

## 空间与设施

- 开放空间：1F – 4F。
- 入口（3 个）：① 西侧 1F 主入口；② 2F 东、西连廊入口。进出需刷实体卡/电子校园卡。
- 静音舱：3F、4F 客梯附近。
- 研修间/讨论间：3F、4F 共 38 间，配备智慧屏或双显示器。
- 金融研究数据实验室：Bloomberg、Wind 终端（Room 310 及 1F、2F 客梯附近）。
- 设备外借：2F Ask Us Desk 可借多种学习设备。
- 电脑与显示器：检索终端、iMac、Windows PC、显示器。
- 打印机：2F、3F、4F；另有 2F 专业图书扫描仪、1F 照片打印机。
- 自助电子储物柜：E4、W4 栋 2F（连廊入口附近）。
