# 💳 支付方式

来源：学校国际学生手册「Payment Options」（2025-03-03）。

## 移动支付

- **微信支付**：支付、转账、缴水电费；支持绑定国际信用卡（Visa、Mastercard、JCB、Diners/大来卡）。
- **支付宝**：功能与微信支付类似，支持支付、转账及理财等。

## 外币兑换

依中国外汇管理规定，外币不可在境内用于流通、计价或结算。可在**中国银行、中国工商银行**等指定银行将美元、英镑、欧元、加元、港币、澳门元、法郎等货币兑换为人民币。

## 银行账户

- 持**护照 + 录取通知书**到银行申请开卡。
- 提交申请后通常约 **1 周**收到银行卡。
- 有本地银行卡可大幅提升生活便利度。

## ATM

广州 ATM 分布广泛（大型商场、商业区、高校周边均有），可提现、查余额、办理其他业务。
