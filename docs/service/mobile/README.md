来源：学校国际学生手册「Telecommunication」（2025-03-03）。

- 套餐一般包含通话时长与流量，各运营商按需提供不同套餐。
- 若无法本人现场办理，可在运营商官方渠道扫码在线申请。

## 如何充值

1. **线上充值**：运营商官网或 App。
2. **充值卡**：在授权零售点购买充值卡，刮开涂层获取密码，按提示输入手机号充值。
3. **营业厅**：前往运营商营业厅，由工作人员协助充值。
4. **微信 / 支付宝**：App 内选择「手机充值」，输入手机号即可充值或查余额（未绑定银行卡时需先绑卡再支付）。
