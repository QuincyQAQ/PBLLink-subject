# 🖥 IT 服务

来源：学校国际学生手册「IT Services」（2025-05-07），见 [studyathkustgz.hkust-gz.edu.cn/StudentSupport](https://studyathkustgz.hkust-gz.edu.cn/StudentSupport)。

## IT 服务窗口

系统操作、故障处理或其他 IT 问题，可联系信息技术处（ITD）：

- **热线**：(020) 88330101
- **报修**：「科大Go」微信小程序 → 报事报修
- **邮箱**：gzit@hkust-gz.edu.cn

## 官网

- [香港科技大学（广州）官网](https://hkust-gz.edu.cn/) — 枢纽/学域介绍、校园新闻等公开信息。

## 校园账号

- 账号是校内成员的唯一身份标识，可登录各类校内应用系统。
- 学生账号格式：`username@connect.hkust-gz.edu.cn`
- 激活账号或修改密码：ITD 网站（校园访问服务）。

## myPortal 统一门户

校内统一门户，集成信息查询、办事、日程管理，可访问 SIS、Canvas、校内 GPT 等系统，并提供公告、校园新闻、活动、科研、ARS 信息及日程日历、借书记录。

- 网页版 + App 版（「HKUSTGZGo」）
- App 安装与登录指南：ITD 网站 → 校园访问服务 → Campus Unified Portal「HKUSTGZGo」安装与登录指南

## 「科大Go」微信小程序

多功能校园助手，集成电子校园卡、校园出入、校园服务、校园管理与支付等功能，含 20 余项应用：校园地图、体育预约、报事报修、扫码借书、预约系统等。

- 微信搜索「科大Go」，用校园账号登录。
- 使用指引：ITD 网站 → 校园访问服务 → HKUST(GZ) Go

## ITD 网站

- 各类应用系统/软件的使用说明与用户指南，均可到 ITD 网站查询。
- 入口：myPortal → Applications → Services → ITD Website

## 校园卡

- 两种形态：**实体卡**与**电子卡**。
- 用途：进入授权区域、使用指定电梯、使用公共打印机、支付等。
- 使用方式：刷实体卡，或在读卡器上出示电子卡二维码。
- 详见：ITD 网站 → 校园访问服务 → Campus Card

## 校园网络

- Wi-Fi 名称：**HKUSTGZ**（网络几乎覆盖全校园）。
- 登录用户名：校园账号前缀（不含 `@connect.hkust-gz.edu.cn`）。
- 密码：校园账号密码。
- 更多网络信息：ITD 网站 → 网络通信服务 → Network。

## 房间预约

- 教室或图书馆自习室：myPortal → Applications → Services → Booking System。
- 使用指南：ITD 网站 → 校园访问服务 → Room Booking。

## 公共打印机

- 教学区与宿舍区均设有公共打印机。
- 按操作系统（Windows / Mac）下载安装对应驱动，再按需使用。
- 使用指南与驱动：ITD 网站 → 办公应用服务 → Printer。
