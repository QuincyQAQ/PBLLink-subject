# 🛏 学生宿舍

来源：学校官网[设施与服务 · 学生宿舍](https://www.hkust-gz.edu.cn/zh/campus-life/facilities-services/student-dormitories/)。

## 概况

香港科技大学（广州）一期学生宿舍共 **7 栋**，合计可居住约 **3500 名学生**，宿舍分为多人套间（六人间、七人间、八人间）、一房一厅、Studio 套间。

## 多人套间

- **独立卧室**：每套多人间设有单独卧室，配床（含床垫）、书桌椅、衣柜。
- **公共客餐厅**：宽敞明亮的公共客餐厅，配休闲沙发、木制茶几、木制桌椅。
- **独立厨房**：干湿分离设计，配抽油烟机、双开门冰箱、电磁炉、微波炉、电热水壶等家电。
- **卫浴间 & 洗漱台**：干湿分离的卫生间和淋浴间，两套独立的双人洗漱台。

## 一房一厅 & Studio 套间

针对已婚（研究生、博士生）及无障碍设施需求的学生，可根据学校管理规定申请。

## 宿舍配套

- **心理驿站**：宿舍内设有心理驿站，是学生心理健康关怀的一环。
- **洗衣房**：宿舍一层设有洗衣房，配洗衣机和烘干机。
- **共享活动空间**：宿舍架空层，划分沙发观影区、休闲娱乐区、厨房吧台区。
- **音乐活动室**：部分宿舍楼栋内设有音乐活动室，供练习和表演。
