# ⚽ 体育设施

来源：学校官网[设施与服务 · 体育设施](https://www.hkust-gz.edu.cn/zh/campus-life/facilities-services/sports-facilities/)。

## 概况

体育设施由**室内体育场馆**和**室外运动场地**两部分组成：

- 室内体育场馆：总建筑面积 14953.67 平方米，共一层，建筑高度 15.85 米。
- 室外运动场：建筑面积 1619 平方米，看台座位 768 个。

## 室内场馆

| 场馆 | 说明 |
|------|------|
| 游泳馆 | 室内恒温国际标准池，长 50m × 宽 21m（8 泳道，深 1.4–2m），348 个观众席；24 小时水循环，6 名持证救生员；免费向教师、职工、学生及家属预约开放 |
| 综合场馆 | 可作 3 个标准篮球场（总面积 2547㎡，360 个电动可收放座椅，进口实木地板）；兼作 6 块羽毛球场、排球+篮球多功能场；可改装为约 1400 座位会议厅 |
| 乒乓球馆 | 249.2㎡，进口实木地板，4 张比赛级球桌，已开放预定 |
| 壁球馆 | 255.45㎡，进口实木地板，防爆玻璃墙，4 间标准场地，已开放预定 |
| 多功能健身房 | 845.87㎡，分健身区、体适能训练区、搏击区；跑步机、椭圆机、健身单车、划船机、楼梯机及力量器械、沙袋架等 |
| 多功能运动室 | 3 间（481.39㎡ / 152.23㎡ / 140.51㎡），一间设羽毛球场地 |

## 室外场地

- **田径场 & 足球场**：400 米标准综合田径场（8 条主跑道，西侧看台下 10 道 110m 直跑道），含 105m×68m 国际标准足球场（人造草坪）。
- **网球场**：看台西侧 3 个标准全场，已开放预定。
- **篮球场**：校园北区 1 个标准室外篮球场。
