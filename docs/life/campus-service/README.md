## 音乐活动室

- 位置：活动中心 C2-206~211
- 开放时间：10:00 – 12:00、15:00 – 21:00
- 提供吉他、钢琴、古筝、电子琴、古琴等琴房
- **预约方式**：通过 BOOKING 系统提前预约

::: tip 证件照提醒
自助证件照机可即时出证件照；但若办理广东省外国人签证照片需要回执单，须到实体照相馆拍摄，或在递交申请材料时于出入境一楼拍摄。
:::
