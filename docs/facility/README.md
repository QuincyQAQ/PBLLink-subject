# 🏫建筑与设施

港科广的校园地图、建筑分布与设施信息分散在官网、小程序和各类文档中，这里按类别汇总官方入口。

## 🗺 校园地图与导航

- **[科大Go 小程序](https://itdid.hkust-gz.edu.cn/en/detail-692)** — 官方小程序，内置 3D 室内外一体化地图，支持定位与导航；访客可查找食堂、电梯、洗手间等设施。
- **[科大Go 使用指引（PDF）](https://itd.hkust-gz.edu.cn/uploadfile/2024/05/15/10-54-14/%E9%A6%99%E6%B8%AF%E7%A7%91%E6%8A%80%E5%A4%A7%E5%AD%A6%E5%B9%BF%E5%B7%9E%E4%B8%A8%E7%A7%91%E5%A4%A7Go%20%E5%B0%8F%E7%A8%8B%E5%BA%8F%E4%BD%BF%E7%94%A8%E6%8C%87%E5%BC%95_V1.0.pdf)** — 校内版/公众版导航详解。
- **[Campus Map（含虚拟导览）](https://studyathkustgz.hkust-gz.edu.cn/detail-819)** — 招生站校园地图页。

## 🏛 校园设计

- [校园设计（简体）](https://www.hkust-gz.edu.cn/zh/about/campus-design/)
- [校园设计（繁体）](https://www.hkust-gz.edu.cn/zh/about/campus-design/?variant=zh-hk)

官网「校园设计」以图片展示主要建筑群：正门、行政大楼、大学活动中心、学术研究枢纽、图书馆、高街（宿舍区商业街）、北宿舍区及运动休闲设施。设计理念上，学术研究区位于中心，八座研究实验楼通过有盖拱廊连接，图书馆是中央枢纽焦点。

## 🔬 红鸟学创空间

红鸟学创空间是港科广融合学科项目式教学的核心实践平台：

- [RBMS 宣传册（PDF）](https://cft.hkust-gz.edu.cn/wp-content/uploads/2024/07/RBMS%E5%AE%A3%E4%BC%A0%E5%86%8C2.0%E5%8E%8B%E7%BC%A9%E7%89%88-20250623.pdf) — 三层大教室（胡杨、梧桐、木棉，位于 W1 教学楼 4–6 层）与多个工作坊的分布、设备与功能。
- [RBMS 目录（PDF）](https://cft.hkust-gz.edu.cn/wp-content/uploads/2024/07/rbms-catalog-2024.pdf) — 各工坊具体楼栋房间号（如材料制备工坊 W3 101、木工模型与 3D 打印工坊 E3 101 等）的分布地图。

::: tip 使用建议
快速了解校园全貌，直接打开「科大Go」小程序最直观；需要某类设施的工坊配置时，再查阅上面的 PDF。
:::
